# FinSync UI/UX Design Direction

## Visual System
- Obsidian-framed navigation (#121110) with crisp off-white canvas (#F4F5F7) and cobalt-blue accents (#2563EB).
- Dual light/dark support.
- Cards: white (#FFFFFF) with #EAECEF borders and soft elevation.
- Inverted featured cards: obsidian (#141312) with white text.

## Typography
- Inter / Plus Jakarta Sans.
- `tabular-nums` for financial metrics and counts.

## Components
- GlassCard, GlassPanel, GlassButton, GlassInput, GlassSelect, GlassTable, GlassDrawer, GlassModal, etc. (restyled, stable interfaces).
- Tab-to-fill placeholders for empty fields.
- Confirmation modals for destructive actions.

## UX Helpers
- Back-to-top button, privacy banner, help FAB, skeleton states, sticky headers, print styles.
